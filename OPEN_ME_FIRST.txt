CurvePress Studio 0.2.0

SOURCE CHECKOUT / SOURCE ZIP
  Windows: double-click run_curvepress.bat
  macOS / Linux: sh run_curvepress.command
  Python 3.11+ and network access are needed for dependency installation.
  Both launchers retry an incomplete installation.

WINDOWS PORTABLE APP
  Download CurvePress-Studio-Windows from a successful "Windows portable app"
  Actions run. Extract the entire ZIP, then run CurvePress/CurvePress.exe.
  Keep the _internal folder beside the executable.
  Python does not need to be installed separately.
  Generated files: %LOCALAPPDATA%/CurvePress Studio/output

Open http://127.0.0.1:8765 if the browser does not appear.
Keep the server console open while using the app; close it to stop.
For an A1 mini, keep the plate within 180 x 180 mm (170 mm recommended).
